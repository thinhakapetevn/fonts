# Oxalis Monobit UI

Hybrid face for single-font menus (fuzzel, powermenu).

- ASCII/Latin text: Single metrics (6 px at 16 px).
- Icon codepoints: Double metrics (12 px at 16 px).
- Generated from the matching Single + Double TTFs; not part of the four canonical faces.

Use: `fuzzel --font "Oxalis Monobit UI:pixelsize=16" ...`
